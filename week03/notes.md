Command	                                Explanation
SELECT VERSION();	                    Displays the installed MySQL Server version.
SELECT CURRENT_USER();	                Shows the MySQL account used for authentication.
SELECT NOW();	                        Displays the current date and time according to the MySQL server session.
STATUS;	                                Displays information about the MySQL connection and server.
SHOW VARIABLES LIKE 'port';	            Displays the port number used by the MySQL server.
SHOW TABLES;	                        Lists the tables in the selected database; currently, none have been created.
